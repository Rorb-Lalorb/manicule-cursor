# Manicule Cursor assets for Digital Humanities Projects
These are art assets made for a digital humanities project, intended as custom cursors, but can be used for other things too.  They are modelled after manicules from the 15th century Danish manuscript AM 76 8vo.  They are 32 x 32 pixels, one in red "ink" and one in black "ink".  Released under a CC0 1.0 Universal license.


How to add these cursors to your digital humanities web project/online exhibit/etc:

1. Upload the .pngs as assets to your website/app/etc.  Make sure you know the path to the folder they are stored in.  

2. In the CSS stylesheet for the website, add this code under the “body” section:
	
	cursor:url(“YOUR PATH TO CURSOR FILE"), auto;


3. If you want to use the other colour of the cursor for hovering over links, add the same code to the “a.hover” section.  

Please enjoy :)
